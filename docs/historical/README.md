# Historical — local-only bin for pre-vault-era root artifacts

The workspace root used to accumulate loose session artifacts (DESIGN-*, STRATEGY-*, HANDOFF-*,
launch-day docs, client notes). They were moved into this directory on 2026-07-03 to clean the
root (`Work/repo-coherence-program` in the team vault).

**Everything in this directory except this README is deliberately untracked** (see the
workspace `.gitignore`): this repo is public, and these files are private session artifacts
that were never committed — some contain client or internal material. They live here locally
for later mining into the team vault's `Decisions/` and `Strategy/` (where that content
belongs), not for publication.

New session output goes to the vault (work-note logs, decision notes) — never to loose root
files, and never here.
